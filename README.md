# 赋新户外

一个纯静态单页网站，用于展示户外服饰款式图片与线下门店信息。没有后台、数据库和下单功能，仅用 HTML、CSS 和少量 JavaScript 实现，无需构建。

## 网站内容

- 款式图按「春秋厚款」（87 款）和「夏季薄款」（54 款）两个分类展示，共 141 张，依编号 001 起顺序排列。
- 顶部固定导航：品牌标识、两个分类锚点、当日日期；小屏自动折叠为菜单。
- 支持按款号、品类、花色、编号搜索；点击图片可放大查看并左右切换。
- 页面底部展示线下门店信息、手机号与微信 / 抖音二维码图片位；右下角有悬浮返回顶部按钮。
- 适配电脑、平板、手机；图片懒加载，网格与放大查看共用同一份图，点开图片无需再等待下载。

## 文件结构

```
index.html            页面本体（HTML / CSS / JS 全内联，无外部依赖）
images/               141 张款式图（700px 长边 WebP，网格与放大查看共用同一份）
```

## 部署

把 `index.html` 和 `images/` 目录上传到 Cloudflare Pages 或任意静态托管即可，其余文件不用上传。

## 上线前需要补充

门店地址、联系电话、手机号，以及微信 / 抖音二维码图片——把页脚两个虚线占位框替换成 `<img>` 标签即可。
